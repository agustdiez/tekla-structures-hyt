# Acero
El propósito de este apartado es describir como modelar en acero, desde sus elementos, con sus conexiones, perfiles y verificaciones. A su vez, como en general el dato de entrada de la estructura vendrá de un modelo, se incluye como importar archivos de programas de elementos finitos (FEM).

- [Conexiones](conexiones.md) - Modelado de conexiones (Placa base/uniones, etc) y listado de componentes
- [Perfiles](perfiles.md) - Modelado de elementos de acero.
- [Importación FEM](importacion_FEM.md) - Tutorial de importación archivos de STAAD a tekla.
- [Verificaciones](verificaciones.md) - Listado de verificaciones previo durante y despues del modelado.
